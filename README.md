# 🚀 Zulora Drive

Enterprise Cloud Storage Platform with Dark Glassmorphism UI. Built with **HTML5, CSS3, JavaScript (ES6+), Node.js, Express, and Firebase Authentication**.

---

## ✨ Features
* 🔒 **Firebase Authentication**: Email/Password & Google Sign-In.
* 📁 **Cloud File Manager**: Upload, view, and organize files smoothly.
* 💳 **Custom Pricing Tier**: Storage upgrade options integrated with FamPay UPI (`shivenpanwar@fam`).
* 📱 **Responsive Design**: Google Drive inspired Mobile & Desktop layout.
* 💬 **Direct WhatsApp Support**: Instant admin verification via (+91 6395211325).
